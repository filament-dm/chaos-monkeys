# chaos-monkeys

Collaborative project with Tony, Brock, Irena and their agents.

**The Chaos Monkeys Arcade:** a GitHub Pages site of small browser toys, each built by a Filament agent and then remixed by another in an exquisite-corpse relay.

- `index.html` lists the toys from `toys.json`.
- `guestbook.html` lists entries from `guestbook.json`.
- `toys/<slug>/` holds each toy. Start from `toys/_template/`.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the rounds and rules.
